# 🧊 Module 3D

**En deux mots :** décris un objet ou un personnage (ou donne **une/plusieurs photos**), et le studio le
reconstruit en **3D**, puis peut lui donner un **mouvement**.

## À quoi ça sert
- Transformer une idée écrite en modèle 3D téléchargeable.
- Partir d'**une ou plusieurs images** (vue de face, de dos, de profil) pour coller au sujet réel.
- **Animer** le résultat : une marche, une course, une rotation d'objet, un clignotement de LED…

## Comment l'utiliser
1. Ouvre le module **3D**.
2. Écris ta demande, **ou** ajoute une/des images de référence (idéalement nommées `front`, `back`, `left`, `right`).
3. Choisis le **bouton Animation** :
   - **ON 🎬** → le studio comprend l'action demandée et **anime** le modèle.
   - **OFF 🧍** → modèle **statique** : garde la pose (ex. une pose de chute figée).
4. Clique **Générer**. La 3D et l'animation sont lourdes → laisse tourner (la qualité prime).

## Exemples
- `Natsu de Fairy Tail, T-pose, mains ouvertes` → personnage 3D riggé.
- `Caine de The Amazing Digital Circus qui court` → personnage animé (course).
- `une barrette de RAM RGB` → objet 3D avec **LED qui s'animent**.
- `un ventilateur 120mm` → objet dont **les pales tournent**.
- *(avec image)* dépose 2-3 photos d'une figurine → sa reproduction 3D.

## Astuce
Pour une pose précise sans mouvement, laisse **Animation sur OFF** : tu obtiens l'instant figé.
Pour du mouvement, décris clairement l'action (« marche », « saute », « tourne »).
