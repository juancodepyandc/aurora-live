# 🖼️ Module Image

**En deux mots :** génère des images à partir d'un **texte**, ou à partir d'une **image de référence**
(pour styliser / éditer / décliner).

## À quoi ça sert
- Créer une image depuis une description.
- Partir d'une **image existante** pour la modifier ou en faire des variantes (édition guidée).

## Comment l'utiliser
1. Ouvre le module **Image**.
2. Écris ta description **ou** dépose une image de référence.
3. Précise le style si tu veux (réaliste, aquarelle, cyberpunk, etc.).
4. **Générer** — la haute qualité prend un peu de temps sur ma config, c'est normal.

## Exemples
- `un renard roux endormi dans une forêt d'automne, lumière douce, photoréaliste`
- `logo minimaliste pour un studio de musique, fond sombre, néon bleu`
- *(avec image)* dépose une photo → `même personnage mais en tenue d'hiver`

## Astuce
Sois précis sur la lumière, le cadrage et le style : c'est ce qui change le plus le rendu.
