# 👨‍💻 Module Code

**En deux mots :** un copilote pour programmer — écrire, corriger, expliquer du code.

## Comment l'utiliser
1. Ouvre **Code**, décris ce que tu veux (langage, objectif).
2. Colle du code à corriger ou à expliquer si besoin.

## Exemples
- `Écris une fonction Python qui lit un CSV et trace un graphe.`
- `Pourquoi ce bout de code plante ? (colle le code)`
